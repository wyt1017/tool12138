## 技术栈

```
React 18       + TypeScript 5.8
React Router 7 (SPA 路由)
Vite 6         + Tailwind CSS 3
Framer Motion  (动效)
Lucide React   (图标库)
@meting/core   (音乐源解析)
Vitest         (单元测试)
Cloudflare Workers (边缘部署 + 边缘缓存)
```

**架构亮点：**
- 所有数据处理完全在浏览器本地完成，无后端服务器
- Cloudflare Workers 边缘函数处理 HTTPS 跳转、CSP 安全头、SPA fallback
- 静态资源通过 Cloudflare CDN 全球加速分发
- 玻璃拟态（Glassmorphism）暗色风格 UI

## 隐私与安全

- ✅ 所有计算、转换均在浏览器本地完成
- ✅ 无第三方数据收集
- ✅ 无用户登录/注册要求
- ✅ CSP 严格限制外部资源访问
- ✅ 外部 API（汇率、天气、GitHub）经 Cloudflare Workers 边缘函数代理，带域名白名单与缓存，不暴露客户端 IP

```
├── src/
│   ├── components/        # React 组件
│   │   ├── DynamicIcon.tsx
│   │   ├── home/
│   │   └── layout/
│   ├── pages/
│   │   ├── Home.tsx
│   │   ├── Tools.tsx
│   │   ├── About.tsx
│   │   └── tools/         # 各工具页面 (85个)

│   │   └── tools.ts       # 工具元数据（名称/图标/路径/分类）
│   ├── config/
│   │   └── site.ts        # 站点域名唯一来源（canonical / og / sitemap 共用）
│   ├── hooks/
│   │   └── useSEO.ts      # 运行时 title / meta / JSON-LD 注入
│   ├── workers/
│   │   ├── index.ts       # Cloudflare Worker 边缘函数

│   └── App.tsx            # 路由配置
├── public/                # 静态资源原样拷贝到 dist/
├── vite-plugin-seo.ts     # 构建期注入 canonical / description，并生成 sitemap.xml
├── wrangler.toml          # Cloudflare Workers 配置
└── vite.config.ts         # Vite 构建配置
```
