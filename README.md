## 技术栈

```
React 18       + TypeScript 5.8
Vite 6         + Tailwind CSS 3
Cloudflare Workers (边缘部署)
Lucide React   (图标库)
```

**架构亮点：**
- 所有数据处理完全在浏览器本地完成，无后端服务器
- Cloudflare Workers 边缘函数处理 HTTPS 跳转、CSP 安全头、SPA fallback
- 静态资源通过 Cloudflare CDN 全球加速分发
- 玻璃拟态（Glassmorphism）暗色风格 UI

## 隐私与安全

- ✅ 所有计算、转换均在浏览器本地完成
- ✅ 无第三方数据收集
- ✅ 无用户登录/注册要求
- ✅ CSP 严格限制外部资源访问
- ✅ 外部 API（汇率、天气、GitHub）由客户端直连，无需经过中转服务器

│   │   ├── DynamicIcon.tsx
